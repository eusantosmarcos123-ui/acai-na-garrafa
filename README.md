# 🍇 Açaí na Garrafa D2C

Plataforma completa de Açaí na Garrafa artesanal com foco em nutrição esportiva, rotina e praticidade.

## 🚀 Funcionalidades Principais
- **Configurador de Kit ("Build Your Box"):** Seleção de 4, 6 ou 12 garrafas (300ml, 500ml e 1L) com cálculo dinâmico de desconto progressivo (7% a 15% OFF).
- **Filtros por Momento de Consumo:** Pré/Pós-Treino (High Protein), Zero Açúcar (Clean Label), Lanche & Refrescância.
- **Logística Térmica & Cold Chain:** Simulador de frete com bolsas isotérmicas seladas e pontos de retirada gratuita (*Click & Collect*).
- **Checkout 1-Clique para WhatsApp:** Geração de mensagem formatada pronta para atendimento ágil.
- **Banco de Dados SQLite:** Persistência relacional de produtos, clientes, pedidos e leads B2B.

## 🛠️ Tecnologias
- **Frontend:** HTML5 semântico, CSS3 moderno, JavaScript ES6+, Lucide Icons
- **Backend:** Node.js, Express, CORS
- **Banco de Dados:** SQLite3 (`database.sqlite`)

## 💻 Como Executar
1. Clone o repositório:
   ```bash
   git clone https://github.com/eusantosmarcos123-ui/acai-na-garrafa.git
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor:
   ```bash
   npm start
   # ou execute iniciar_servidor.bat
   ```
4. Acesse: `http://localhost:3000`
